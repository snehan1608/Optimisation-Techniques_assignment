# Optimization Techniques Assignment

Python implementations of standard linear programming and operational research optimization algorithms using NumPy.

---

## Algorithms Included

* **`Big-M.py`**: Solves Linear Programming Problems (LPP) using the Big-M Simplex method with artificial variables.
* **`Transportation.py`**: Solves transportation problems to find initial basic feasible solutions / optimal allocation costs.
